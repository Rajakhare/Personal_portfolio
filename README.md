# Personal Portfolio 🚀

My personal portfolio website showcasing my projects, skills, and experience 
as a Python and MERN Stack Developer.

## Live Demo

https://raj-akhare-portfolio.netlify.app/

## Sections

- **Hero** - Introduction and call to action
- **About** - Background and experience
- **Skills** - Technical skills and technologies
- **Projects** - Showcase of built projects
- **Contact** - Get in touch

## Tech Stack

- React.js
- HTML5
- CSS3
- JavaScript
- Deployed on Netlify

## Features

- Fully responsive design
- Mobile friendly layout
- Clean and modern UI
- Smooth navigation
- Cross browser compatible

## Installation

1. Clone the repository
   git clone https://github.com/Rajakhare/personal-portfolio.git

2. Install dependencies
   npm install

3. Run locally
   npm start

4. Build for production
   npm run build
